# 店员操作规则

给实际记账的人看，不需要懂技术。

## 多商家（给平台方看）

- 一套系统可以服务多家店，每家店的玩家、班次、押金、流水、设置完全隔离，互相看不到。
- 每个账号只属于一家店；用户名全平台唯一，登录后自动进入自己店，不用选商家。
- 一个人同时只能在一种店里：换店要新建账号。
- 开店、改名、停用商家只能用命令行（找维护的人）；店老板登录后在「设置 → 账号管理」自己给店员开号。
- 每家店可以同时各有一个进行中的班次，互不影响。
- 停用商家后该店所有账号立即无法登录，数据保留；重新启用即可恢复。

## 每天开始：开班

点「场次」→「开班」。一个班次就是一个批次，这一班的所有局和押金变动都会记在它下面。
一个店同一时间只能有一个进行中的批次，交班之后才能开下一班。

## 开一局

1. 「场次」→「新增场次」
2. 场次名称可以留空，系统自动按「10月31日 第1局」命名
3. 填每人茶水（默认上次用的数），选最多 10 个人
4. 底部会实时显示「茶水合计」和「有几个人会扣成负数」
5. 点「创建」，每个人的押金自动扣掉茶水，总局数 +1

余额不够也能开局，会扣成负数；但确认前会弹窗提醒，这时最好让对方先补押金。

## 押金操作

在「玩家」页，每一行右边有四个操作：

| 操作 | 规则 |
| --- | --- |
| 加押金 | 必须大于 0，余额增加 |
| 扣押金 | 可以是 0，也可以扣成负数（罚款、补差价都行） |
| 退押金 | 不能超过当前押金，负数账户不能退 |
| 划押 | 把钱从一个玩家转给另一个，可以划成负数；转出和转入会各记一条流水 |

划押默认金额是「茶水 × 10」，可以直接改。

## 押金颜色

- 红色：低于 30 元，需要提醒对方补押金（负数也是红色）
- 黄色：30 到 60 元
- 绿色：高于 60 元

阈值管理员可以在「设置」里改。

## 交班

「场次」→ 当前批次右边的「交班」。

系统会先算好这一班的：局数、人次、茶水合计、加押金、退押金、手动扣押、划转笔数、期末总押金。
确认后这个批次就锁住，不能再往里面加场次，汇总数字保存成快照，之后改设置也不会变。

交班时如果提示「对账不通过」，说明有人直接改过数据库里的余额，找管理员处理，不要强行交班。

## 看记录

「记录」页有两个标签：

- **押金记录**：每一笔钱的变动，谁操作的、什么原因、在哪个场次
- **场次记录**：每一局有几个人、茶水多少、谁开的

顶部搜索框可以搜玩家名或场次名；也可以选日期范围。

## 账本

「账本」页是按批次汇总的表，可以导出 CSV 给老板或对账用。

口径说明：
- 划转只算转出方（一笔划转两边金额相等、方向相反，相加是 0）
- 期末总押金是交班那一刻全店押金合计
- 期初 = 期末 − 本批净变动

## 账号

- 店员：能开局、加/退/扣/划押金、建玩家、改备注
- 管理员：额外能删玩家（押金必须为 0）、改设置、开账号、重置密码、跑对账
- 账号管理只能管本店的人：看到和能操作的都只有自己店的账号。

忘记密码找管理员重置，管理员重置后需要重新登录。
