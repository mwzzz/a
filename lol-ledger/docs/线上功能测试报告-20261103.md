## 三、发现的问题

### P2 · 茶费 0 的局会把「默认茶水」覆盖成 0

**复现**

1. 设置里默认茶水为 3 元；
2. 开一局，把「每人茶水」填 0（免茶水局）；
3. 再看设置，默认茶水变成 0.00。

**证据**：测试中执行上述步骤后，接口 `GET /api/v1/settings` 返回 `last_tea_cents: 0`（测试前为 300）。下一局开局弹窗的茶水默认值也随之变成 0。

**影响**：店员开过一次免茶水局后，之后所有开局的默认茶水都是 0，若不手动改，会漏收茶水钱，且没有任何提示或报错。

**根因**：`backend/app/services/sessions.py:186` 无条件记忆本次茶水：

```186:186:backend/app/services/sessions.py
    options.set_int(session, merchant_id, "last_tea_cents", int(tea_fee_cents), actor.id)
```

**建议**：仅当 `tea_fee_cents > 0` 时记忆，0 元局不覆盖默认值（或前端在 0 元时二次确认）。

### P3 · 分页组件 deprecated 告警

浏览器控制台唯一告警：`[el-pagination] [API] small is about to be deprecated in version 3.0.0, please use size instead.` 不影响功能，升级 Element Plus 前改掉即可。

### 设计确认（非缺陷，供你判断）

1. **删除玩家后流水仍在**：软删除后其押金流水仍出现在「最近流水」和流水明细里（本次测试清理时在工作台看到 `zzt-f 退款 10.00`）。符合「玩家软删除、流水永久保留」的设计，但会让已删玩家的名字出现在工作台。
2. **分红结算不可撤销**：结算后只能靠数据库回滚，当前没有「撤销结算」入口，符合本期范围，但误结算需要人工处理。
