# 押金记账

用简体中文和用户沟通。这个目录是一个 Windows 桌面记账程序（PySide6 + SQLite）加一个授权服务和一个静态官网。仓库根目录下还有别的项目，只改 `neizhanjizhang\`。

动手做功能、改规则或排查问题之前，先读 [交接文档.md](交接文档.md)。下一阶段的云端账本计划在 [docs/plans/云端账本开发计划.md](docs/plans/云端账本开发计划.md)，状态是已确认但未开始；用户没有明确说做之前，不要动手。

## 命令

在本目录执行：

- 运行：`python -m app.main`（或 `run.bat`）
- 测试：`python -m pytest tests -q`
- 打包和发布官网的步骤见交接文档第九节

## 必须遵守

- 金额在库里是整数分，界面显示元。不要用浮点数存钱。
- 导入账本用 `shutil.copyfile` 加 `ensure_writable`。不要改回 `copy2`，否则会把来源文件的只读属性复制过来。
- 加押金、退押金、划转必须作用在押金记录输入框里当前的游戏 id 上，不能用上一次查询的人。
- 玩家库按总局数排序。只有开一局按最近一次扣茶水排序。
- 用户没要求时不要提交 git，不要改试用开关，不要把卡密写进文件或回复。
- `data\deposit.db` 已被 git 跟踪，里面可能是真实账本。不要提交它的改动，也不要自行把它移出仓库。`data\license.json` 和服务器上的 `cards.db` 同样不要外传。
- 官网文案里不写授权服务器地址，也不写卡密。
- 不要修改 `C:\Users\Administrator\.cursor\plans\` 里的计划文件。
