四个页面

收钱、开局、查账、交班，
一条动线走完。

01

玩家库

一屏看清谁还剩多少押金

  • 游戏 id、押金、总局数、备注，按总局数从高到低排
  • 总押金常驻页面上方，对现金不用按计算器
  • 批量导入 txt / csv，一行一个，可带备注
  • 导出 Excel 快照，用来对账或发给店主
  • 只有押金为 0 才允许删除，避免误删有余额的人
02

开一局

选人、填茶水、确认，三步

  • 「选前 10 个」一次勾上最常来的十位，再点一次取消
  • 名单按最近一次扣茶水的时间排，熟客在前
  • 确认前就能看到每个人的「扣后押金」
  • 扣成负数的会单独列出来，再让你确认一次
  • 确认那刻的茶水写进本局，之后再改不影响历史
03

押金记录

每一笔钱都有出处

  • 加押金、退押金、划给其他人，三种动作都记流水
  • 流水含时间、原因、变动额、当时押金、操作后押金、局号
  • 游戏 id 可以下拉选，也可以打字回车直接查
  • 划转两边同时落账，不会出现只扣不进
  • 退押金和划出不能让余额低于押金，负数账户会挡住
04

交接班

换人、换电脑都不断账

  • 导出的是整个账本文件，含全部玩家与流水
  • 在新电脑上导入，接着原来的账往下记
  • 导入前自动在本机留一份备份，覆盖错了也有退路
  • Excel 只是名单快照，交接只认账本文件

怎么装

解压、双击、输入卡密，
三步就能开局。

  1. 1 下载并解压

    把 zip 解压到任意文件夹，建议放在 D 盘这类平时不会清空的位置，不要只把 押金记账.exe 单独拖出来。

  2. 2 双击运行

    运行文件夹里的 押金记账.exe。同目录的 _internal 文件夹是运行库，删掉程序就起不来。

  3. 3 输入卡密

    第一次打开会要求卡密，向管理员索取。进去后先批量导入玩家，或从上一个账本导入，再开始开一局。

账本会自动建在 exe 旁边的 data\deposit.db。要备份，就把这个 data 文件夹整个复制走。

授权

一台电脑一份卡，账本始终是自己的。

卡密登录

程序打开时输入卡密。同一张卡可以装在多台电脑上，但同一时间只允许一台在线，关掉程序就立刻让出。

只有授权在联网

验证与心跳走网络，账本数据不上传，也不需要登录任何账号。断网时已开着的程序会在几分钟内锁住，账本文件不受影响。

过期就续，卡号不变

卡到期由管理员在原卡上加天数，卡密不变；正在用的人不用退出重登，加完继续用。

常见问题

上手前想知道的几件事

数据存在哪里？会不会被上传？

存在你自己电脑上，是 exe 旁边 data\deposit.db 这个 SQLite 文件。程序只把卡密和机器码发给授权服务器做验证，玩家名单和流水不出本机。

必须一直联网吗？

打开程序时要能连上授权服务，之后大约每 20 秒一次心跳。连续两次连不上，界面会锁住并只允许退出。网络恢复后重新打开、重新登录即可，账本数据一直都在。

换电脑怎么把账带走？

旧电脑「交接班 → 导出账本」，得到一个 .db 文件；新电脑上「交接班 → 导入账本」，选这个文件即可。导入前程序会在本机先备份一份当前账本。

误开了一局，能撤销吗？

不能。局数和扣掉的茶水都已经写下，需要把押金补回去，就用「押金记录 → 加押金」记一笔，流水里会留下这条更正记录。

押金会被扣成负数吗？

会。茶水大于当前押金时，确认前会把这些人单独列出来，确认后照记，余额变负；之后加押金补上。这样做是为了不让欠账从账面上消失。

导出的 Excel 能当交接文件吗？

不能。Excel 只是导出那一刻的玩家名单快照，没有历史流水。交接只认导出的整个账本文件。

为什么 Windows 会弹「已保护你的电脑」？

安装包没有做代码签名，SmartScreen 会对陌生的 exe 提示一次。点「更多信息」，再点「仍要运行」就可以。文件是从这里下载的、SHA-256 与下载页一致，就不必担心。

有 Mac 或网页版吗？

目前只提供 Windows 版本，界面是桌面原生窗口，没有网页版，也不需要浏览器。
