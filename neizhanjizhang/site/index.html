01

玩家库

一屏看清谁还剩多少押金

  • 游戏 id、押金、总局数、备注，按总局数从高到低排
  • 押金分红、黄、绿三色，低于 30 元的人一眼就能找出来
  • 搜索框按游戏 id 或备注定位，回车跳到下一个
  • 总押金常驻页面上方，对现金不用按计算器
  • 批量导入 txt / csv，一行一个，可带备注；也能导出 Excel 快照
  • 只有押金为 0 才允许删除，避免误删有余额的人
02

开一局

选人、填茶水、确认，三步

  • 名单按最近一次扣茶水排，上一局的人在最前
  • 「选前10个」一次勾回上一桌，不够十人就全选，再点取消
  • 点一行任意位置就能勾选，不用对准小方框
  • 确认前就能看到每个人的「扣后押金」，扣成负数的单独列出
  • 茶水金额会记住，下次打开还是上次填的数
  • 确认那刻的茶水写进本局，之后再改不影响历史
03

押金记录

每一笔钱都有出处

  • 加押金、退押金、划给其他人，三种动作都记流水
  • 流水含时间、原因、变动额、当时押金、操作后押金、局号
  • 游戏 id 可以下拉选，也可以打字回车直接查；从玩家库双击直接跳过来
  • 退押金默认填全部余额，且不能超过余额
  • 划给其他人默认是茶水的 10 倍，余额不够也能划，变负数前先确认
  • 划转两边同时落账，不会出现只扣不进
04

交接班

换人、换电脑都不断账

  • 导出的是整个账本文件，含全部玩家、流水和上次的茶水
  • 在新电脑上导入，接着原来的账往下记
  • 导入前自动在本机留一份备份，覆盖错了也有退路
  • 别人发来的账本带「只读」属性也不怕，导入后照常能记
  • Excel 只是名单快照，交接只认账本文件

怎么装

解压、双击、登录，
三步就能开局。

  1. 1 下载并解压

    把 zip 解压到任意文件夹，建议放在 D 盘这类平时不会清空的位置。不要放在「Program Files」里，也不要在压缩包里直接双击运行。

  2. 2 双击运行

    运行文件夹里的 押金记账.exe。同目录的 _internal 文件夹是运行库，不要只把 exe 单独拖出来。

  3. 3 登录并导入

    登录框里填卡密（向管理员索取）后点登录。进去后先批量导入玩家，或从上一个账本导入，再开始开一局。

账本会自动建在 exe 旁边的 data\deposit.db。升级新版时，把旧版的 data 文件夹复制到新版 exe 旁边即可，玩家和流水都还在。

授权

同一时间一台电脑在线，账本始终是自己的。

卡密登录

程序打开时登录。同一张卡可以装在多台电脑上，但同一时间只允许一台在线，关掉程序就立刻让出。

只有授权在联网

验证与心跳走网络，账本数据不上传，也不需要登录任何账号。断网大约 40 秒后，已开着的程序会锁住并只能退出，账本文件不受影响。

过期就续，卡号不变

卡到期由管理员在原卡上加天数，卡密不变；正在用的人不用退出重登，加完继续用。

常见问题

上手前想知道的几件事

数据存在哪里？会不会被上传？

存在你自己电脑上，是 exe 旁边 data\deposit.db 这个 SQLite 文件。程序只把卡密和机器码发给授权服务器做验证，玩家名单和流水不出本机。

必须一直联网吗？

打开程序时要能连上授权服务，之后大约每 20 秒一次心跳。连续两次连不上，界面会锁住并只允许退出。网络恢复后重新打开、重新登录即可，账本数据一直都在。

押金的红、黄、绿是什么意思？

低于 30 元（包括负数）是红色，鼠标停在押金上会提示「请及时补押金」；30 到 60 元是黄色；60 元以上是绿色。颜色只是提醒，不会限制开局。

押金会变成负数吗？

会，两种情况：开一局时茶水大于当前押金；或者划给其他人时划出的比余额多。两种都会先列出来或弹窗让你确认，确认后照记，之后加押金补上。退押金不能超过当前余额，所以负数账户退不了。

换电脑、换管理员怎么把账带走？

旧电脑「交接班 → 导出账本」，得到一个 .db 文件；新电脑上「交接班 → 导入账本」，选这个文件即可。导入前程序会在本机先备份一份当前账本。上次填的茶水金额也会跟着账本过去。

打开时报「attempt to write a readonly database」怎么办？

这是旧版的问题：导入别人发来的账本时，把对方文件的「只读」属性一起带了进来。换成新版后打开即可，程序会自动去掉只读，账本里的玩家和押金都还在。如果提示「账本无法写入」，说明程序放在了不能保存文件的位置，换到 D 盘之类的普通文件夹再运行。

误开了一局，能撤销吗？

不能。局数和扣掉的茶水都已经写下，需要把押金补回去，就用「押金记录 → 加押金」记一笔，流水里会留下这条更正记录。

导出的 Excel 能当交接文件吗？

不能。Excel 只是导出那一刻的玩家名单快照，没有历史流水。交接只认导出的整个账本文件。

为什么 Windows 会弹「已保护你的电脑」？

安装包没有做代码签名，SmartScreen 会对陌生的 exe 提示一次。点「更多信息」，再点「仍要运行」就可以。文件是从这里下载的、SHA-256 与下载页一致，就不必担心。

有 Mac 或网页版吗？

目前只提供 Windows 版本，界面是桌面原生窗口，没有网页版，也不需要浏览器。
